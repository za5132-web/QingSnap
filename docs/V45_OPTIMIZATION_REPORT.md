# QingSnap Preview v45 优化报告

## 结果摘要

| 指标 | v44 / 完整模式 | v45 轻量模式 | 变化 |
| --- | ---: | ---: | ---: |
| 主程序发布体积 | 52.34 MB | 24.74 MB | -52.7% |
| 空闲工作集（本机实测） | 188.6 MB | 106.6 MB | -43.5% |
| 空闲私有内存（本机实测） | 110.2 MB | 42.7 MB | -61.3% |
| 自动回归测试 | 0 | 13 | 新增 |

完整包仍包含 PP-OCRv6 扩展，总体积为 52.34 MB；轻量包保留区域截图、长截图、标注、贴图、历史记录和 Windows OCR。完整包实测可正常加载高级运行时，后台预热成功，并完成一次 5 行真实图片识别。

## 长截图

- 撤销检查点从无限累计改为最近 3 步，避免每一屏都长期持有上一整帧。
- 首次完成滚动区域初始化后立即释放首帧副本。
- 最终图片改用 `WriteableBitmap` 分段写入，不再额外创建一份与完整长图等大的连续托管数组。
- 完成长图后立即释放帧、拼接段和撤销缓存。
- 诊断日志记录每屏位移、匹配置信度、输出尺寸和估算保留内存。

## OCR

- “极速”模式在程序空闲时预热高精度引擎。
- “节能”模式按需加载，闲置 5 分钟后自动释放。
- 64 × 64 视觉指纹支持不同图片对象之间复用识别结果，LRU 上限为 24 项。
- WPF 像素直接复制到 Skia 原生缓冲区，减少一次整图内存复制。
- 高精度引擎独立放在 `AdvancedOcr` 目录；缺少扩展时自动使用 Windows OCR，不会下载无用模型。

## 贴图与剪贴板

- 屏幕边缘停靠几何计算从贴图窗口中拆出，统一处理左右边缘、露出宽度、垂直安全区和 DPI。
- 图片、截图区域和文字复制使用独立 STA 工作队列；剪贴板被占用时，重试不再冻结主界面。

## 历史记录

- 新增收藏与收藏筛选。
- 新增长截图筛选。
- OCR 完成后建立本地文字索引，可直接在历史窗口搜索识别内容。
- 列表使用回收式虚拟化，缩略图解码宽度由 360 px 调整为 260 px。

## 诊断与测试

- 日志位于 `%LOCALAPPDATA%\QingSnap\Logs`，单文件最大 4 MB，保留 7 天。
- 托盘菜单可以导出 ZIP 诊断包；系统信息不包含截图、OCR 正文或历史目录路径。
- 回归测试覆盖重复帧、尺寸变化、滚动位移、撤销、构建后释放、贴图边缘布局、OCR 内容缓存、设置归一化、诊断包和历史 OCR 索引。
