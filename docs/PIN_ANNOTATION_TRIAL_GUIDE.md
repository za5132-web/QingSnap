# 贴图二次标注 · 本机试用说明

状态：用户已于 2026-11-04 确认发布，纳入 v1.1.3。本文件保留试用操作说明供使用和回归检查；此前试用包沿用 1.1.2 程序版本号。

## 如何试用

1. 按 F3 贴出图片，右键选择“标注图片”，或直接按 F2。
2. 在临时图标工具条选择画笔、箭头、双箭头、直线、矩形、椭圆、文字、序号、马赛克、模糊、高亮或选择工具。
3. 颜色位于工具条第二行；鼠标放在已有标注上滚轮调整粗细/字号。
4. F2 切到选择，再按 F2 或双击单个文字/序号标注进入编辑；Shift+单击/框选多选，支持移动、Delete、Ctrl+C/V、Ctrl+Z/Y/Shift+Z、图层快捷键和 WASD 精确移动。
5. 编辑文字时键盘交给文字输入框，支持中文输入；Enter 提交文字、Esc 取消本次文字编辑。非文字编辑状态下 Enter/Esc 或工具条对钩完成标注，不会关闭贴图。完成后 Esc 恢复为关闭贴图。
6. 编辑状态 Ctrl+C 有选中标注时复制标注供 Ctrl+V 粘贴；工具条“复制完整标注图片”始终复制整张图。非编辑状态 Ctrl+C 保持原逻辑：有选中文字则复制文字，否则复制图片。
7. 另存按钮或右键“另存图片”导出独立 PNG；不覆盖截图历史原图。

**新增标注仅保留在当前贴图窗口中。关闭前请复制或另存。** 再次进入同一贴图的标注模式可以继续编辑及撤销；截图中本来已经烘焙为像素的旧标注无法拆成可编辑对象。

## 长图联动

- 包含原选区大小阅读窗、滚轮阅读、双击概览/返回和收纳恢复修复。
- 标注按整张图片的像素坐标保存，滚动时跟随图片；导出包含当前窗口外的完整长图。
- 普通滚轮放在标注上调整参数；空白区域保留阅读滚动/普通图缩放。Ctrl+滚轮保留缩放。
- 标注结束后正常拖动贴图；M 收纳会先结束标注。普通收纳与边缘投放恢复均保留标注。
- 每个贴图使用独立的标注文档和撤销栈。

## 识别与隐私

- 开始标注、修改、撤销/重做后清除旧的 OCR 文字、选字框和二维码热点，取消旧识别任务。
- 完成后 OCR 按合成图片重新准备；二维码同样读取合成图。旧识别完成回调通过任务身份检查，不会重新显示编辑前的结果。
- 标注时暂停自动选字，避免选字和绘制互相抢鼠标；结束后恢复。
- 原图和历史文件未被擦除，仍然保留原始内容；另存或复制的是合成图片。

## 实现及文件

- `StickyImageWindow.Annotations.cs`：贴图编辑状态、临时工具条、输入路由、完整图合成、另存和识别失效处理。
- `StickyImageWindow.xaml`：普通/长图标注 Viewbox、自绘工具按钮、右键入口。
- `StickyImageWindow.xaml.cs`：复制、OCR/QR、键盘、模式切换和窗口生命周期接入。
- 直接复用 `CaptureAnnotationController`，不建立平行标注模型。图片像素作为文档坐标，Viewbox 负责显示缩放和鼠标坐标映射；撤销、多选、端点、文字、序号、马赛克和图层沿用已有实现。
- `PinAnnotationTests.cs`：新增 6 项测试，覆盖普通/长图完整输出、可见范围外标注、撤销重做/清空恢复、视图切换/再编辑、首次文字提交、旧 OCR 失效、小缩略图和真实工具条渲染。
- 此试用包同时包含 `LongImagePinLayout.cs`、`LongImagePinLayoutTests.cs` 与 `LONG_IMAGE_PIN_READER_REPORT.md` 所述更新。

## 明早人工验收

1. 普通图片：画箭头、框、文字，F2 编辑、Shift 多选移动，Ctrl+Z/Y，复制到聊天软件核对清晰度。
2. 长图：滚到下方再标注，双击概览/返回、M 收纳/恢复、拖到左右边缘恢复；核对位置及阅读进度。
3. 文字/序号：中文输入，Enter/Esc，双击与 F2 编辑数字；文字编辑中 WASD/Ctrl+C 不应移动或复制标注。
4. 马赛克后完成标注：检查不再选择编辑前的旧文字；复制/另存 PNG 核对完整尺寸及遮挡效果。
5. 退出再进入编辑，确认新增对象可改；关闭再 F3 为原图是预期行为，需保存时使用“另存”。
6. 外部剪贴板、透明图片、小贴图、150% DPI、副屏与负坐标屏幕分别试用。
7. 同时打开多个贴图，切换编辑窗口，检查工具条不会留在其他应用之上。
