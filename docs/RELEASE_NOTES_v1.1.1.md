# QingSnap v1.1.1

QingSnap v1.1.1 集中改进首次使用体验：把原有功能罗列式教程重构为一条可以在一分钟内理解的七步工作流，并为每一步加入不触发真实用户数据的模拟操作动画。

## 本次更新

### 七步动态新手教程

- 开始截图：演示 `F1`、智能窗口识别与自由框选。
- 精确选区：演示 X/Y/W/H、16:9、固定尺寸与 1px 微调。
- 标注编辑：演示箭头、矩形、文字、多选、撤销和重做。
- 截取长图：演示固定栏、滚动重叠、自动拼接与手动补截。
- 贴到桌面：演示 `F3` 贴图、滚轮缩放、`M` 收纳、悬停展开与恢复。
- 提取信息：模拟文档式选字、`Ctrl+C`、二维码热点和主动打开链接。
- 搜索复用：模拟历史全量搜索、标签、来源、贴图、`R` 与再次截取。

### 视觉与可访问性

- 统一深色 Keycap、操作提示、图标层级、圆角和演示区视觉。
- 修复侧边收纳状态下红底白色图钉可能被贴图容器裁切的问题。
- 修复二维码动画鼠标偏离热点、点击后遮挡热点的问题。
- 修复 OCR 动画中的 `Ctrl+C` 组合键在较窄演示区显示不全的问题。
- 继续尊重 Windows“减少动画”：降级后直接显示每页关键状态，不出现空白演示区。
- 教程标题栏版本号读取当前程序集版本，不再硬编码。
- GitHub 项目主页重写为更清晰的下载、工作流与核心能力结构，并提供简体中文、English、繁體中文、日本語、한국어五种独立语言页面。

### 稳定性

- 页面切换前统一停止并复位旧动画，避免快速导航时跨页残留或动画叠加。
- 教程关闭后移除所有动画；首次完成状态保存失败会记录日志而不会阻止软件启动。
- 完成 50 个教程窗口循环，每个窗口执行 20 次七页往返；窗口计数、GDI、USER、线程和私有内存未出现线性增长。

## 兼容性

- 保持 v1.1.0 的截图、长截图、贴图、OCR、二维码、历史、快捷键、配置与数据库行为。
- 支持 Windows 10/11 64 位、.NET 8、WPF、Per-Monitor V2 DPI。
- OCR 仍是可选模块；教程不会触发 OCR 安装、模型下载、真实识别或剪贴板读取。

## 下载

下载 `QingSnap-v1.1.1.zip` 后解压运行 `QingSnap.exe`。

本版本使用 QingSnap 自签名证书。Windows 仍可能显示未知发布者或证书链不受信任提示。请从 QingSnap GitHub Release 页面下载，并使用随附的 `.sha256` 文件校验压缩包。
