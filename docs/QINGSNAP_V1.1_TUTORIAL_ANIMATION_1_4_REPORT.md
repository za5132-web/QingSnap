# QingSnap v1.1 首次教程第 1～4 页动画报告

## 1. 每页动画实现

### 第 1 页：F1 开始截图

- 使用内置模拟窗口呈现应用标题栏和内容区。
- 鼠标先进入窗口，青色智能识别框与“单击 · 智能选区”提示淡入。
- 鼠标随后回到自由框选起点，并从左上向右下移动。
- 智能识别框淡出，自由选区同步扩大，截图蒙层出现，选区内部保持明亮。
- 松开状态显示 `680 × 453 px` 尺寸和轻量工具栏轮廓。
- 单轮约 3.8 秒，停留后自动循环。

动画只表达智能选区与自由框选，没有演示比例、固定尺寸、标注或长截图。

### 第 2 页：精确选区

- 从已经建立的选区开始，鼠标拖动右下角，选区宽高连续变化。
- `W / H` 使用离散关键帧随拖动显示中间数值，几何面板同步突出。
- 比例状态从“自由”切换为 `16:9`，第二次调整使用 304 × 171 的严格比例状态。
- 锁定尺寸后，四角手柄弱化并显示“尺寸已锁定”。
- 整体拖动时 `X / Y` 改变，`W / H` 保持不变。
- 最后显示放大镜和 `D · +1 px`，选区与放大镜准星同步移动 1px。
- 单轮约 4 秒。

### 第 3 页：标注与编辑

- 工具栏依次突出箭头、矩形和文字。
- 箭头以绘制缩放方式出现，随后矩形和演示文字依次出现。
- `F2 · 选择` 状态出现后，矩形显示单选手柄并移动。
- 状态切换为 `Shift · 多选`，箭头与矩形外显示整体包围框并一起移动。
- `Ctrl+Z · 撤销` 将组合移回原位；`Ctrl+Y · 重做` 再次恢复位置。
- 单轮约 4 秒。

未逐项展示画笔、椭圆、马赛克、高亮或模糊。

### 第 4 页：截取长图

- 模拟网页使用独立固定顶部栏，滚动内容位于其下方，因此顶部栏始终只出现一次。
- 长图按钮先突出，截图选区青色框始终保留。
- 内容分两段向上滚动，进度依次显示 `1 / 3`、`2 / 3`、`3 / 3`。
- 两次拼接位置短暂显示青色 `OVERLAP · 已对齐` 提示。
- 最后淡入长图结果缩略预览，显示“自动拼接”，旁边保留低权重“手动补截”。
- 单轮约 4 秒。

动画没有出现屏数、像素高度、内存、重试次数或重叠比例等保护参数。

## 2. 动画时钟与生命周期

- 沿用 `FirstRunTutorialWindow.StartAnimation`、`StopAnimations` 和关键帧辅助方法。
- 没有新增 `DispatcherTimer`、后台线程或独立动画框架。
- 数值与状态文本使用 WPF `StringAnimationUsingKeyFrames`，移动、尺寸和透明度继续使用 `DoubleAnimationUsingKeyFrames`。
- 所有动画由元素自身的 WPF 动画时钟持有。
- 切换页面前统一调用 `StopAnimations`，移除旧页面的数值、文本、位置和透明度动画。
- 返回页面时根据初始状态重新创建循环动画。
- 窗口 `Closed` 时继续调用 `StopAnimations`，不会留下 Timer 订阅或窗口强引用。
- 动画只操作教程内部模拟元素，不调用截图、剪贴板、OCR、历史记录或文件写入服务。

## 3. Reduce Motion 行为

当系统关闭客户端区域动画时，第 1～4 页进入 `StartReducedMotion`：

- 不执行鼠标移动、选区拖动、标注位移或页面滚动路径。
- 先设置可理解的最终静态状态。
- 再通过三段低运动量淡入依次展示关键状态。
- 第 1 页依次显示智能识别、自由选区、尺寸与工具栏。
- 第 2 页依次显示几何数据、16:9、尺寸锁定和 1px 放大镜状态。
- 第 3 页依次显示三类标注、多选包围框和编辑状态。
- 第 4 页依次显示重叠对齐、长图结果、自动拼接和手动补截。

第 5～7 页保持原有减少动画静态降级行为。

## 人工检查项

1. 从设置页重新播放教程，观察第 1 页是否清楚呈现智能选区与自由框选两种方式。
2. 检查第 1 页自由选区内部明亮、外部蒙层和松开后的尺寸/工具栏。
3. 检查第 2 页 W/H 变化、16:9、锁定尺寸、整体移动和 D 微调顺序。
4. 检查第 3 页箭头、矩形、文字、F2 单选、多选、撤销和重做顺序。
5. 检查第 4 页固定顶部栏是否只出现一次，并确认两次重叠对齐提示。
6. 在第 1～4 页之间快速来回切换，确认旧动画立即停止并从头重新播放。
7. 使用 `←`、`→`、`Enter`、`Esc` 和页面按钮检查导航未退化。
8. 开启 Windows“在 Windows 中显示动画”关闭状态，确认只出现关键状态淡入，没有拖动或滚动。
9. 在 100%、150%、200% 缩放下检查模拟区域没有裁切或错位。
