# QingSnap v1.1.8：贴图收纳悬停预览

日期：2026-11-19。基于正式 v1.1.8（`d10b607`），独立分支 `feature/pin-dock-hover-preview`。不混入翻译实验版、主工作区未完成的冷启动改动；版本号不变，本次不上传 GitHub。

## 入口与默认值

设置 → **贴图收纳** → **悬停缩略图，预览原位置的贴图**。

默认关闭，兼容旧配置。预览不透明度默认 80%，滑块范围 20%～100%，保存后对现有贴图及新贴图生效；正常贴图自身不透明度保持不变。设置沿用已有深浅主题、字体、间距和青色强调，自绘滑块显示百分比，没有系统浅色滑块混入。

## 动画与状态规则

| 开关与操作 | 行为 | 动画 |
| --- | --- | --- |
| 关闭：悬停缩略图 | 原缩略图在边缘展开 | 保留原 Reveal 动画 |
| 关闭：单击 / M / 右键恢复 | 恢复正常贴图 | 保留原 Dock 恢复动画 |
| 开启：悬停缩略图 | 先完整展开缩略图，停留 1 秒后在收纳前位置显示半透明预览 | 先保留原 Reveal 动画，再复用 190ms 预览插值与 EaseOut |
| 开启：1 秒等待期间单击 / M | 不等待，不创建预览，直接正式恢复 | 只播放一次原恢复动画 |
| 开启：移开缩略图 | 短暂容错后收回预览，贴图仍收纳 | 原 180ms 离开防抖 + 同一套返回动画 |
| 开启：预览完全展开后单击 / M | 转为正式贴图，隐藏缩略图，恢复正常不透明度 | 不重新启动恢复动画 |
| 开启：向外动画中单击 | 将本次动画标记为正式恢复；继续当前动画到终点 | 不重置开始时间、插值或 Rendering 订阅 |
| 开启：返回途中又悬停 / M | 从当前预览位置反向到原位置 | 不跳回缩略图起点，不叠加多套动画 |
| 开启：真正拖动缩略图 | 终止预览，按原逻辑拖动与吸边 | 不误判为点击恢复，不改收纳前恢复位置 |
| 预览时关闭功能 | 关闭临时预览，缩略图保留 | 不产生新的正式贴图、不抢焦点 |
| 正式恢复交接时关闭功能 | 正式贴图已恢复，释放剩余预览 | 不再收回正式贴图 |

缩略图完整展开后，在预览期间保持该 HWND/尺寸/展开位置不动，是唯一鼠标热区。复用离开防抖并加约 3 DIP 边缘容错；不把原位置预览当热区，因此不会因为预览覆盖鼠标而反复开关。预览窗口不激活、无任务栏图标、鼠标穿透，不干扰底层软件输入。

预览转正式贴图时复用原恢复状态与长图滚动偏移恢复逻辑，但绕过再次动画。等待正式窗口布局与两次渲染交接后撤去覆盖，避免瞬时露空。用户启用系统“减少动画”时，沿用现有 `ClientAreaAnimation` 降级路径，直接到达关键终态。

## 资源、坐标和兼容性

- 收纳时只记录原图像素视口。第一次悬停才生成带标注的当前视口快照，不触发 OCR、剪贴板、历史保存或桌面截图。
- 普通贴图保留图片比例；长图和固定阅读窗只预览当前查看区域，不把整张数万像素长图烘焙成新位图。
- 快照任一轴最多 2048px，像素缓冲最多约 16MiB；原图片复用。无可见预览时不持有额外快照，返回完成/拖动/禁用/关闭时释放。
- 该数字只是快照像素缓冲上限，不是整个进程或 WPF/DWM 总内存承诺。
- 原位置、缩略图位置及动画插值均为物理屏幕像素，允许负坐标、跨屏和不同 DPI；预览的透明度不写回正式贴图。
- 新增的 `PinDockHoverPreviewEnabled` 和 `PinDockHoverPreviewOpacity` 使用原设置 JSON，缺字段默认关闭/80，非法透明度限制到 20～100。
- 只调整这两项设置不重新注册全局快捷键、不重启 OCR；关闭贴图时解除设置事件、Rendering 回调、待执行交接和 native hook。
- F1、F2、F3、Shift+F1、Esc、Enter、Ctrl+Z/Y、OCR 选字、QR、二次标注、原有 M 收纳与边缘吸附入口不改。

人工验收步骤：

1. 保持默认关闭，验证 M 收纳、边缘缩略图悬停展开、点击恢复与旧版一致。
2. 开启并保存，贴一张图拖到明确位置，M 收纳；悬停边缘图钉，确认预览回到该位置、缩略图不动且仍可点击。
3. 移开、快速反复进入/退出以及鼠标紧靠最边缘，确认无循环弹跳或遗留预览。
4. 预览已经展开和刚开始动画时分别单击缩略图，确认只完成一次恢复，不重新从边缘播放，原位置、比例和正常不透明度不变。
5. 拖动缩略图换位置；下一次预览/正式恢复仍回原贴图位置，下一次收纳仍回已移动的缩略图位置。
6. 调整 20/50/80/100% 并保存；只影响预览。预览中关闭功能，确认缩略图还在，点击仍可恢复。
7. 长图滚动到中段、普通图启用固定阅读窗后放大局部、二次标注后分别测试，核对预览内容与原位置/偏移。
8. 多贴图同时收纳；关闭其中一个，不得关闭其他预览。预览中按 M、Esc，检查不遗留透明窗口。
9. Windows 10/11、125/175% 及混合 DPI 多屏、负坐标屏、跨屏拖动、系统减少动画分别实机检查。当前自动化不替代这些实体显示环境测试。

已知限制：预览是短期静态视口，不可在预览层滚动、标注或选字；需要操作时单击缩略图转正式贴图。极大贴图的预览采用有界降采样，不保证原像素 1:1 清晰度。快照不显示 OCR/QR 交互标识与关闭按钮，正式恢复后这些能力仍由原窗口提供。

## 侧边缩略图不收起：用户反馈后的追加修复

原因：开启悬停预览后，统一的“移开”入口转交给大图预览，但边缘投放先生成的是完整展开的缩略图。如果大图预览从未打开，关闭请求会直接返回；即使打开过，返回完成也没有继续收起缩略图。

修复：将缩略图原有 Reveal/Resting 动画独立为 `SetCollapsedThumbnailRevealed`。没有打开过大图预览时，移开直接走缩略图收起；打开过时，先完成预览返回，再收起永久缩略图。预览期间热区不移动，点击正式恢复不受影响；关闭模式沿用原行为。

新增 6 项左/右边缘投放回归，分别覆盖预览开关、从未预览、预览后移开；检查原位置保存、最终露边宽度与资源释放。修复只涉及 `StickyImageWindow.xaml.cs`、`StickyImageWindow.DockHoverPreview.cs` 和对应测试。

本机修复采用备份后替换相同试用程序路径，避免已有启动入口仍指向旧功能版；不修改用户设置、图片或 GitHub 下载包。最终复测及签名文件校验记录以同目录修复包为准。
