# QingSnap（轻截）完整功能清单

> 截得准，拼得长，贴得住；需要文字识别时，再安装 OCR。

QingSnap 是一款面向 Windows 10/11 的轻量截图工具，将区域截图、自动与手动长截图、专业标注、桌面贴图、离线 OCR、二维码识别和截图历史整合在同一套工作流中。

本文档对应 QingSnap `v1.1.0` 正式版功能状态。

---

## 1. 区域截图

- 默认按 `F1` 启动区域截图。
- 支持鼠标自由框选截图范围。
- 鼠标悬停时自动识别窗口和标准控件，单击即可采用智能选区。
- 支持从四条边和四个角继续调整已经建立的截图选区。
- 支持双击、按 `Enter` 或点击工具栏确认按钮完成截图。
- 支持按 `Esc` 或鼠标右键取消截图。
- 设置中可以启用额外的关闭按钮；启用后 `Esc` 仍然可以关闭。
- 支持 0、1、3、5 秒延时截图。
- 截图完成后可以自动复制到剪贴板并保存到截图历史。
- 截图保存和剪贴板复制相互独立；剪贴板被占用时不会导致已经保存的截图被判定为失败。

## 2. 精确选区与像素辅助

- 截图选区显示明确的 `X坐标`、`Y坐标`、`宽度 W` 和 `高度 H`。
- 可以直接输入 X、Y、宽度和高度，精确定位截图区域。
- 使用物理截图像素计算，兼容 Windows DPI 缩放。
- 支持 Per-Monitor V2 DPI、多显示器、负坐标显示器和跨屏选区。
- 像素放大镜保持像素正方形，不会横向或纵向压扁画面。
- 放大镜十字准星对齐像素边缘，便于定位两个颜色的交界位置。
- 放大镜实时显示物理屏幕坐标和 HEX 颜色。
- 按 `I` 可以复制当前像素的 HEX 颜色。
- 使用 `W/A/S/D` 可以将截图十字准星每次移动 1 个物理像素。
- 中文输入法开启时，字母快捷键仍能生效，并避免把按键继续输入到底层文本框。

## 3. 最近截图范围

- 截图界面按 `R` 可以读取上一次截图范围。
- 连续按 `R` 可以循环最近五个不同的截图选区。
- 循环时显示当前位于最近选区历史中的序号。
- 跨显示器历史范围会自动切换到对应屏幕。
- 默认按 `Shift+F1` 可以直接调出最近一次截图范围并继续交互。
- 调出历史范围后仍可调整位置、尺寸、比例、标注和截图方式。

## 4. 固定宽高比截图

- 支持自由比例。
- 支持 `1:1`、`4:3`、`3:2`、`16:9` 和 `9:16`。
- 支持锁定当前已经框选出的宽高比。
- 锁定比例后拖动角点会严格保持比例。
- 修改宽度或高度数值时，会自动计算另一维。
- 多次缩放后继续以物理像素校正比例，避免明显的累计误差。
- `Shift+拖动角点` 可以临时锁定当前比例。
- 解除锁定后立即恢复自由调整。

## 5. 固定尺寸截图

- 可以输入任意宽度和高度，例如 `800×800`、`1920×1080`、`750×1000`。
- 尺寸区域旁提供锁头图标，不额外占用一个大型按钮。
- 锁定后截图选区只能移动，不能通过四边或四角改变大小。
- 输入新的宽度或高度后，锁定尺寸立即更新。
- 仍可通过 X、Y 输入或拖动选区定位。
- 固定尺寸与固定比例可以共存；同时启用时固定尺寸优先。
- 尺寸超过当前显示器时不会产生负尺寸或错误坐标，并沿用多屏边界规则进行合理处理。
- 已为后续截图尺寸预设功能预留数据结构。

## 6. 专业缩放约束

- `Alt+拖动角点`：以选区中心为锚点进行对称缩放。
- `Shift+拖动角点`：保持宽高比。
- `Alt+Shift+拖动角点`：中心缩放并保持宽高比。
- 支持四个角点。
- 中心缩放时对角同步移动，选区中心保持稳定。
- 触碰显示边界时不会产生负宽高或突然跳跃。
- 当前尺寸栏在调整过程中实时更新。
- 永久比例锁定启用后不依赖 Shift；Alt 仍可控制中心锚点。
- 固定尺寸启用时禁止缩放。

## 7. 截图工具栏

- 工具栏采用深色、自绘、图标化界面。
- 工具栏跟随截图选区显示，并尽量避免遮挡选区内容。
- 提供画笔、直线、箭头、矩形、椭圆、文字、序号、选择、撤销、长截图、OCR、标签、贴图、复制、保存和完成等入口。
- 直线与箭头为独立工具。
- 箭头延伸面板支持单头箭头和双头箭头。
- 矩形延伸面板集成普通矩形、区域马赛克、区域高亮和区域模糊。
- 各绘制工具的颜色选择集成在对应延伸面板中。
- 快速标签按钮属于工具栏的一部分，不再悬浮在工具栏外侧。
- 完成按钮固定在最右侧；启用关闭按钮时，关闭按钮位于最右端。
- 工具栏长度会随实际功能按钮变化，不保留无意义空位。

## 8. 截图标注工具

- 自由画笔。
- 直线。
- 单头箭头。
- 双头箭头。
- 矩形。
- 椭圆。
- 文字。
- 序号标注。
- 区域马赛克。
- 区域高亮。
- 区域模糊。
- 支持自定义标注颜色。
- 支持调整线条粗细、文字大小和序号大小。
- 鼠标位于已有标注上时，可以使用滚轮调整相应的粗细或大小。
- 箭头采用头部较大、尾部较细的实心箭头造型。

## 9. 标注选择与再次编辑

- 按 `F2` 可以从任意绘制工具进入选择工具。
- 选择工具中再次按 `F2` 可以编辑选中的文字或序号。
- 单个标注选中后显示原有编辑手柄。
- 标注可以移动和缩放。
- 直线可以调整起点和终点。
- 箭头可以调整端点、指向和方向。
- 文字内容可以再次编辑。
- 序号标注可以双击、按 `F2` 或通过右键菜单手动修改数字。
- 修改序号后，新建序号会从当前最大数字继续。
- 支持复制、粘贴和删除标注。
- 支持图层上移、下移、置顶和置底。
- 标注右键菜单使用与软件统一的深色自绘样式。

## 10. 标注多选

- 单击选中单个标注。
- `Shift+单击` 添加或取消某个标注的选择。
- 在空白区域拖动可以显示选择矩形并框选多个标注。
- 支持从左上到右下和从右下到左上框选。
- 点击空白区域取消全部选择。
- 多选后显示整体包围框。
- 多个对象可以一起拖动，并保持相对位置不变。
- `Delete` 一次删除全部选中对象。
- `Ctrl+C` 复制全部选中对象。
- `Ctrl+V` 粘贴为一组新的标注，保持相对位置并整体略微偏移。
- 粘贴后新对象自动成为当前选择。
- 多选对象可以整体上移一层、下移一层、置顶或置底。
- 多选不会破坏文字双击编辑、序号编辑和线条端点编辑。

## 11. 标注键盘精确移动

- 选择标注后使用 `W/A/S/D` 移动 1 个截图实际像素。
- `Shift+W/A/S/D` 移动 10 个截图实际像素。
- 支持单选和多选。
- 多选移动时保持对象相对位置不变。
- 100%、125%、150%、175%、200% DPI 下均按照物理像素换算。
- 文字正在编辑时，按键继续用于文字输入，不移动标注。
- 精确尺寸输入框获得焦点时不会截获按键。
- 连续按键会合并为合理的历史操作，避免产生大量撤销记录。

## 12. 完整 Undo / Redo

- `Ctrl+Z` 撤销。
- `Ctrl+Y` 重做。
- `Ctrl+Shift+Z` 同样用于重做。
- 撤销按钮会根据当前状态自动启用或禁用。
- 右键撤销按钮可以通过延伸菜单执行重做。
- 新建、删除、移动和缩放标注均可撤销和重做。
- 直线、箭头端点和方向调整可撤销和重做。
- 文字内容、序号数字、颜色、线宽、文字大小和序号大小修改可撤销和重做。
- 粘贴、清空全部标注和图层顺序调整可撤销和重做。
- 一次完整鼠标拖动只生成一条历史记录。
- 连续滚轮调整和键盘移动采用合并策略。
- 撤销后执行新的操作，会自动清空原有 Redo 历史。
- Undo/Redo 后保持正确的选择状态、标注顺序和导出结果。
- 操作历史最多保留最近 200 条，避免超长标注会话无限占用内存。

## 13. 自动长截图

- 可以从截图工具栏或托盘进入自动长截图。
- 截图蒙层在长截图过程中保持在顶层，交互不会突然跳回桌面。
- 自动滚动目标页面。
- 等待画面稳定后截取当前帧。
- 自动分析相邻画面的重叠区域并完成拼接。
- 检测页面底部后自动停止。
- 按 `Enter` 可以提前结束并完成拼接。
- 按 `Esc` 可以取消。
- 匹配失败时自动返回最后成功位置，缩小滚动步长后重试。
- 可以撤销最后一屏并重新补截。
- 连续画面不稳定时可以切换为手动补截。
- 支持大面积空白页面和稀疏内容页面。
- 可以识别固定标题栏和固定底部操作栏，避免在长图中重复出现。
- 设有 60,000px 高度、80屏和256MB预测内存保护。

## 14. 手动长截图

- 可从托盘、工具栏或可配置的全局快捷键进入。
- 用户可以逐屏滚动并截取下一屏。
- 支持完成拼接、撤销上一屏和取消。
- 自动匹配不稳定时可以继续手动补截。
- 拼接过程保留最后成功状态，减少错误接缝。
- 自动与手动模式共用长图内存和尺寸保护。

## 15. 长图阅读器

- 长截图贴出后自动进入长图阅读窗口。
- 使用滚轮浏览长图内容，不需要把整张数万像素长图一次缩到极小。
- 显示阅读进度。
- 支持 `Home` 回到顶部。
- 支持 `End` 跳到底部。
- 支持 `PageUp`、`PageDown` 和空格翻页。
- 双击可在阅读窗口和完整长图概览之间切换。
- 长图贴图同样支持收纳、恢复、OCR选字和二维码识别。

## 16. 普通桌面贴图

- 默认按 `F3` 贴出最近图片。
- 截图生成的贴图默认出现在原截图位置。
- 外部剪贴板图片默认出现在鼠标位置。
- 支持微信、QQ、浏览器、Office等应用复制出的图片。
- 对异常 Alpha 通道进行修复，避免外部剪贴板图片显示为黑图。
- 连续按 `F3` 循环最近五张图片，而不是重复贴同一张。
- 截图和外部剪贴板图片共用同一历史序列。
- 重复图片会自动合并。
- 可以同时存在多个贴图窗口。
- 支持拖动、滚轮缩放、恢复 `1:1`、适应屏幕和再次复制。
- 极大和极小缩放时保持原始宽高比。
- 使用统一缩放倍数，避免宽高分别触底造成变形。
- 对 Windows 窗口尺寸限制进行等比回退。
- 消除最小缩放附近的滚轮空转区间。
- 贴图不再显示容易被裁切的常驻悬浮工具条，操作集中到右键菜单。

## 17. 贴图边缘收纳

- 按 `M` 可以把普通贴图或长图贴图收纳为屏幕边缘缩略标签。
- 再次按 `M` 或单击缩略标签可以恢复贴图。
- 缩略标签包含当前图片缩略图。
- 标签自动吸附到最近的屏幕边缘。
- 平时只露出小部分提示区域，悬停时自动展开。
- 图钉提示使用红底白色图标，便于识别。
- 缩略窗可以自由拖动。
- 展开与收纳分别记忆位置。
- 从缩略状态展开时回到收纳前的原始贴图位置。
- 再次收纳时回到用户最后移动过的缩略窗位置。
- 将完整贴图用力拖到屏幕左侧或右侧并松开，可以直接通过动画收纳到鼠标位置。
- 收纳和展开带平滑过渡动画。
- 优化边缘悬停判定，避免贴近屏幕边缘时反复展开和收起。
- 缩略图圆角使用透明边缘，不再出现黑色四角。

## 18. 离线 OCR 模块

- 基础程序默认不强制包含 OCR 运行库。
- 不安装 OCR 时，截图、长截图、标注、贴图、历史和二维码功能仍可正常使用。
- 设置中可一键下载、安装、校验、重装和卸载 OCR 运行库。
- 用户不需要手动寻找或选择 ZIP 文件。
- 支持 PP-OCRv6 Tiny 模型，体积较小、速度较快。
- 支持 PP-OCRv6 Small 模型，复杂中文和中英文混排识别率更高。
- Tiny 与 Small 使用各自正确的模型和字典，可以随时切换。
- 支持极速和节能性能策略。
- 极速模式可在空闲时预热 OCR 引擎。
- 节能模式按需加载，并在空闲后释放。
- OCR 直接读取截图像素，减少重复编码和磁盘中转。
- 相同图片的 OCR 结果可以通过视觉指纹缓存复用。
- 截图过程中可以后台预识别，为贴图选字提前准备。
- OCR 后台处理不阻塞截图、复制和贴图。
- OCR 失败会进入日志，并可按现有策略回退。

## 19. 贴图直接选字

- 普通贴图和长图贴图都可以直接像文档一样拖选文字。
- 不需要先从右键菜单进入“选取文字”模式。
- 不长期显示分词框，保持图片主体干净。
- 选择完成后按 `Ctrl+C` 复制文字。
- `Ctrl+A` 可以选择当前贴图中的全部 OCR 文字。
- 文字选择框随贴图移动、缩放和长图滚动保持正确位置。
- OCR 准备过程中采用低干扰状态提示。
- OCR 结果窗口支持重新识别和复制全文。

## 20. 完全离线二维码识别

- 二维码识别内置于基础程序，不依赖 OCR 模块。
- 图片和二维码内容不会上传到服务器。
- 支持 QR Code。
- 同时兼容 Data Matrix、Aztec 和 PDF417。
- 截图工具栏 OCR 延伸菜单提供“识别文字”和“识别二维码”。
- 历史记录右键可以识别二维码。
- 普通贴图和长图贴图右键可以识别二维码。
- 长图采用重叠分块识别，避免一次解码完整超长图片。
- 可以同时识别一张图中的多个二维码。
- 识别完成后在二维码原位置显示轻量可点击热区。
- 鼠标悬停热区可查看二维码内容。
- URL 必须由用户主动点击后才会打开，不会自动跳转。
- 普通文本内容可以复制。
- 特别长的内容在界面中会限制展示长度，但复制时保留完整内容。
- 识别失败只显示轻提示，不弹出复杂错误框。

## 21. 截图历史窗口

- 截图可以自动保存到历史记录。
- 历史窗口采用与主界面统一的深色自绘样式。
- 支持列表模式和图标模式切换。
- 支持刷新和直接打开历史文件夹。
- 卡片显示截图时间、尺寸、文件大小、文件名、标签和来源摘要。
- 可以收藏和取消收藏截图。
- 可以贴图、OCR、识别二维码、打开、复制和删除单张截图。
- 双击预览区域可以打开原图。
- 删除操作进入 Windows 回收站。
- 支持 PNG、JPG 和 BMP 历史图片。
- 用户手动删除外部文件后，刷新时会自动清理失效记录。

## 22. SQLite 历史 Metadata

- 图片文件继续作为普通 PNG、JPG、BMP 文件保存在历史目录中。
- SQLite 只保存 Metadata 和索引，不保存图片二进制。
- Metadata 包括路径、截图时间、宽高、文件大小、格式和长截图状态。
- 保存收藏、OCR文本及索引状态。
- 保存来源程序、窗口标题、显示器信息和物理截图范围。
- 保存图片 SHA-256 哈希、创建时间和更新时间。
- 使用参数化 SQL、事务、WAL 和后台单写入队列。
- 新截图完成后异步持久化，不阻塞截图主线程。
- 删除截图时同步删除数据库记录和标签关系。
- 自动导入旧版收藏文件和 OCR 文本索引。
- 兼容旧版配置，缺少新字段时使用安全默认值。
- 数据库损坏时移开损坏文件，重新创建数据库并从图片目录恢复基础索引。
- 数据库重建不会删除截图图片。
- 普通模式数据库位于 `%LOCALAPPDATA%\QingSnap\history-metadata.db`。
- `portable.flag` 模式下数据库跟随程序目录下的 `Data` 目录。

## 23. 截图来源信息

- 新截图记录来源进程名称，例如 `chrome.exe`。
- 记录截图开始时的前台窗口标题。
- 自动避开 QingSnap 自己的蒙层和工具窗口。
- 自动长截图和手动长截图尽量保留原滚动窗口来源。
- 无法获取来源时字段留空，不影响截图。
- 不收集除进程名和当前窗口标题以外的不必要信息。
- 历史卡片以低干扰方式显示来源。
- 可以按来源程序或窗口标题关键词搜索。

## 27. 历史记录全量分页

## 29. 历史 UI 虚拟化与缩略图优化

- 历史列表继续使用 WPF Recycling 虚拟化。

- 增加最多 150 张的 LRU 缩略图缓存。
- 当前和最近浏览的缩略图优先保留，超限后淘汰最久未使用项。
- 文件路径、修改时间或尺寸变化时自动形成新缓存键。
- 删除截图时同步移除对应缓存。
- 历史目录迁移或刷新时旧缓存可以正确失效。
- 历史窗口关闭时释放窗口专属缓存。
- 普通分页结果不长期携带完整 OCR 正文、原始 Bitmap、byte数组或图片流。

## 40. 性能与资源生命周期

- 截图主流程不等待 SQLite Metadata 写入。
- 历史查询、统计、搜索和筛选异步执行，并支持取消。
- 历史10,000条 Metadata 时仍只加载首屏分页数据。
- 历史窗口滚动使用分页、预取、虚拟化和有限缩略图缓存。
- OCR结果使用视觉指纹缓存复用。
- OCR引擎每完成24次未命中缓存的完整识别后安全轮换，限制 ONNX 原生工作区持续增长。
- 缓存命中不计入 OCR引擎轮换次数。
- 历史、设置、OCR结果、贴图、截图蒙层和长截图窗口关闭时取消后台任务并释放资源。
- 长截图完成后释放拼接帧缓冲。
- Clipboard STA 队列复用单个后台线程，并在应用退出时安全停止。
- 更新检查复用 HttpClient，不频繁创建网络资源。
- 二维码识别不会形成原生资源累积。
- 不通过频繁 `GC.Collect()` 掩盖生命周期问题。

## 41. 日志与异常保护

- 新增异常进入 QingSnap 现有日志体系。

- 后台异常不会轻易导致 QingSnap 整个托盘进程退出。
- 日志默认只保留最近7天。

- Release正常运行时不启动诊断采样计时器，不增加日常常驻开销。
