# 长图贴图阅读窗调整

## 行为

- 有原截图选区的纵向拼接图片，即使整体宽高比不足 2.15，也进入现有长图阅读器。
- 初始窗口位于原选区，内容按窗口宽度等比显示，超出的纵向内容通过滚轮查看；不再对原选区强制应用旧阅读窗最小值与工作区百分比限制。
- 外层保留贴图细边框，因此原生窗口比选区每边多 1 个物理像素。
- 双击切换完整适屏概览，再双击恢复阅读窗位置、尺寸、缩放及滚动比例。OCR 文字上的双击也可切换；普通图片双击行为不变。
- 继续复用现有滚动、OCR 选字、二维码热区、M 收纳、Esc、Ctrl+滚轮缩放等设施。

## 修改文件

- `src/QingSnap.App/Views/StickyImageWindow.xaml.cs`：识别入口、原生窗口定位、DPI 转换、视图切换与阅读位置恢复。
- `src/QingSnap.App/Services/LongImagePinLayout.cs`：阅读器判定及物理像素转 DIP。
- `tests/QingSnap.Tests/LongImagePinLayoutTests.cs`：新增 9 项自动化用例，包括真实 HWND 初始尺寸、重复切换、100/125/150/175/200% 数学换算与普通截图保持原行为。

## 人工检查

### 边缘收纳恢复修复

- 已复现：恢复动画将长图滚动轨道压缩到 32px 以下，旧 `Math.Clamp(value, 32, trackHeight)` 因最小值大于最大值抛异常，打断恢复过程。
- 修复：小轨道下缩小滑块下限；动画与收纳期间不覆盖阅读进度，恢复结束重新定位到原阅读比例。
- 回归用例先在旧实现复现异常，修复后通过；现已同时覆盖 M 收纳/恢复和模拟边缘投放动画/恢复，核对最终原生窗口位置及尺寸。
- WPF 窗口测试归入同一串行测试集合，避免并发创建 Application 导致测试环境竞态。
- 160 项测试通过；仍排除会操作真实开机启动项的 1 项迁移测试。

1. 选择一个较宽区域制作长图，按 F3；核对窗口位置和可见尺寸与蒙层选区一致。
2. 在窗口内滚轮浏览，确认窗口大小不变，长图不拉伸。
3. 滚到中间后双击适屏，再双击返回；反复切换，检查阅读位置和窗口恢复。
4. 在 OCR 文字上双击，检查同样切换；拖选后 Ctrl+C 仍正常。
5. 检查 Ctrl+滚轮、Shift+滚轮、M、Esc、右键原始宽度及回到顶部。
6. 普通图片滚轮缩放及双击切换保持不变；F3 最近五张循环仍正常。
7. 在副屏、负坐标、混合 DPI、跨屏选区重复上述过程。
