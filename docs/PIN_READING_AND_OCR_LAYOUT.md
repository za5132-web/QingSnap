# 贴图阅读与 OCR 排版

适用于 QingSnap v1.1.7 及后续兼容版本。

## 固定窗口，看内部细节

1. 按 F3 贴出图片。普通滚轮仍缩放整张贴图和窗口。
2. 按住 Ctrl 滚动：自动进入固定窗口阅读，窗口保持原大小，内部内容放大。
3. 用滚轮上下查看，Shift+滚轮左右查看；空格+左键或中键拖动平移图片。单纯拖动空白仍移动窗口。
4. 普通阅读窗双击可先看完整图片，再双击回到上次细节。长图仍双击切换阅读窗/完整概览。
5. 右键可选择内容适应窗口、内容原始大小、恢复默认贴图，也可取消固定窗口阅读。

内容小于窗口时居中，不会被拉伸。平移到边缘会停止，不会把图片完全拖丢。原始大小按当前显示器物理像素计算；显示器切换后的实际观感仍建议核对。

图片中的文字、二维码热点和标注跟随图片位置。按 M 或拖到边缘收纳后，恢复时保留阅读位置。复制/保存始终输出完整图片及标注，不会因为窗口只显示局部就裁掉其他部分。

阅读状态只存在当前贴图中，关闭后不会保存为全局设置。空格现在用于平移，翻页使用 PageUp/PageDown；文字正在编辑时空格仍然正常输入。

## 复制更自然的文字

贴图文字识别完成后，像文档一样拖选并按 Ctrl+C。轻截会保守整理明确分栏和正文自然折行，并在字框证据充分时修复部分异常空格；不会补入未选中的行或使用 AI 改写原文。

保留原样的方式：

- 贴图选中文字后右键 → **按原始换行复制**：仅复制选中内容，保留原识别顺序、空格和换行。
- OCR 结果窗口右键 **复制全文** 按钮 → **复制原始识别全文**：取未经本轮排版的原始全文。

OCR 编辑区仍可手动校正。正常 Ctrl+C 和复制全文使用当前编辑区内容，不会自动覆盖手动修改。历史搜索索引保留原识别文字，本轮不会重新识别旧记录。

短行、列表、诗词、代码、路径和明显表格结构优先保留换行。因为策略保守，部分短正文或带缩进的自然折行可能仍保留较多换行。

## 边界与隐私

- 本功能是轻量后处理，不提高模型本身认错字的准确率；缺失/错误字框、复杂表格、合并单元格、旋转/竖排及混成一行的分栏内容可能需要手动校对。
- 基础截图、贴图和二维码不依赖安装 OCR。OCR 仍按需安装，无新增翻译模型或在线服务。
- 排版只使用现有本地识别结果，不上传图片或文字；没有新增常驻计时器、模型或后台录屏。
- 不新增数据格式，不影响既有设置、OCR 模型与历史数据库。
