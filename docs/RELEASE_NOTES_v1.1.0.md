# QingSnap v1.1.0

QingSnap v1.1.0 把专业选区调整、完整标注编辑、全量历史管理、离线二维码和更新中心整合进现有轻量截图工作流，并完成了面向长期日常使用的性能与资源稳定性优化。

## 本次重点

- 完整 Undo / Redo：`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- 标注多选、框选、批量移动/删除/复制粘贴/图层调整。
- `W/A/S/D` 以物理像素精确移动标注，`Shift` 配合移动 10px。
- 固定比例、当前比例、固定尺寸、X/Y/W/H 精确输入。
- `Alt` 中心缩放、`Shift` 比例约束和组合操作。
- SQLite 历史 Metadata、截图来源记录、多标签与截图时快速标签。
- 历史列表/图标双模式、多选和批量操作。
- 移除历史最近 500 张限制，改为全量搜索、80 条分页、滚动预取和虚拟化。
- 280px 按需缩略图解码与 150 张 LRU 缓存，浏览大量历史后内存趋于稳定。
- 全局快捷键 2.0：直接按键录入，支持截图、长图、贴图、OCR、历史和暂停/恢复。
- 完全离线二维码识别，并在二维码原位置显示可点击热区。
- 设置页新增版本检查、下载、SHA-256 校验和打开下载目录。
- OCR 引擎、剪贴板、长截图、历史窗口及后台任务完成资源生命周期加固。

## 兼容性与数据

- 支持 Windows 10/11 64 位、.NET 8、WPF、Per-Monitor V2 DPI。
- 完整兼容 v1.0.2 配置、截图文件、收藏和 OCR 索引。
- 图片继续作为普通 PNG/JPG/BMP 文件保存，不写入 SQLite。
- 首次运行会在后台建立 Metadata，历史图片不会被删除或改名。
- `portable.flag` 用户的数据库继续跟随便携数据目录。
- OCR 仍为可选模块；未安装 OCR 时，截图、长图、标注、贴图、历史和二维码识别均可正常使用。

## 下载与校验

下载 `QingSnap-v1.1.0.zip` 后解压运行 `QingSnap.exe`。本版本使用 QingSnap 自签名证书，Windows 仍可能显示未知发布者或证书链不受信任提示。

SHA-256：`FE02968164AD7A1F66348CEADC85AB004F8EAAA85AF036127DACD6AC171B1FE1`

QingSnap 更新中心会在下载后自动校验；同一校验值也随 GitHub Release 的 `.sha256` 附件发布。
